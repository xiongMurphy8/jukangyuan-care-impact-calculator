# 现站审计与设计取舍

审计日期：2026-08-31。对象为用户提供的聚康源网站，桌面1280×720、移动端390×844。仅进行页面读取和虚构输入测试。

## Inference

企业初筛场景需要明确输入、结果和限制条件。当前装饰性渐变、宋体大标题、英文标签和重复卡片弱化了工具感。优先解决排版、对比度和层级，比增加复杂动效更适合此页面。

## Opinion / 实施取舍

采用保留品牌和业务流程的轻量改版。首页引入一张有明确 AI 标注的就业场景图。测算表单和金额明细属于产品 UI，不机械套用营销页“不得使用表格”等规则，也不为了达到图片数量要求再添加无业务作用的照片。

法律免责声明、授权说明、政策链接、字段顺序与 URL 锚点不变。只缩短营销介绍文字并统一操作标签。没有访问或修改管理员数据。

原网站排名和流量无可用证据，未推测 SEO 排名。上线应沿用原 URL、核对原事件埋点，并在正式源代码项目中补充 SEO 验收。预览刻意设置 noindex。

## Pre-flight 状态

已检查：页面定位与 dials、改版审计、主要导航保持、两行首屏、按钮可见、导航高度、明暗主题、强调色与圆角一致性、CTA标签与单行显示、正文与按钮文字对比度、减少动态效果、明确移动布局、图片来源标注、没有伪造客户数字/评价、没有装饰版本标签、没有滚动提示、没有破折号、没有手绘 SVG、没有虚假 UI 截图、没有额外框架、空状态与资格不满足状态、咨询提交拦截。

不适用：消费品配色、斜体降部、logo墙、评价长度、Bento计数与视觉变化、GSAP/Three.js、React Motion客户端隔离、RSC状态、磁吸/视差/无限循环、横向滚动接管、滚动堆叠。该页面不存在这些组件。

有意保留：原生数据表（测算结果和政策说明的功能需要）、原有心形品牌标识、法务长文、系统中文字体。它们不作为套用纯营销页规则的整改对象。

待验证：完整 Lighthouse / Core Web Vitals、PDF下载产物逐页检查、真实CRM后台流程和税务规则正确性。没有把这些项目标记为通过，因此交付称为本地视觉预览，不称为正式上线完成。
